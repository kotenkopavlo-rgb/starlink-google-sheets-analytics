# Task 10 — Customer Value Visualization

## Business Question

Which countries have the highest customer value?

## Analysis

Average revenue per customer was used as the primary metric to compare customer value across countries. The results were visualized using a bar chart sorted in descending order.

## Key Findings

Japan has the highest average revenue per customer, while Germany has the lowest. Overall, the difference between countries is relatively small.

## Tools

- Google Sheets
- SORT
- Bar Chart
- AVERAGE
